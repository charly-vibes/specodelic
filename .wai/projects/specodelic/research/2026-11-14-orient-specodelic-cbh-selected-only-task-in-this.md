ORIENT: specodelic-cbh selected (only task in this run). Repo charly/specodelic, main at 1a7ee10, clean. Two decisions: (1) kernel-grammar gate placement — lint accepts kernel cells that compile rejects (empty marker, unclosed paren, ∨, acyclic(traces_to), resolves(nonexistent_col), forall c in Constraint). Decision: compile is the grammar gate; lint intentionally stays grammar-agnostic (schema/reference integrity), because the kernel parser (src/kernel.rs parse_kernel_str / grammar_failures) is the single grammar authority and a second lint-side grammar would duplicate it and drift; document this in a decision note plus kernel spec Notes and contributor guidance. (2) src/graph.rs's TYPED_REFERENCE_COLUMNS is a hardcoded 7-list while acset::schema::canonical carries the typed columns (10 incl. uses/from/to); a new typed column would be silently omitted from graph extraction. Decision: derive the set at runtime from the canonical Schema, excluding the explicitly non-graph columns from/to (the transitions walk owns them) and uses (outbound leaf per graph total_extraction/packs), with a gate test asserting every canonical column is either extracted or exempt. Behavior must remain byte-identical (same 7 columns).
