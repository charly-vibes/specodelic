# Minimum expression kernel (three-tier)

The survey's recommendation, grounded over `src/acset`: split the unverified-expression problem by the job the cell does. Tier A (graph/set/pattern/uniqueness/shape cells) stays prose, verified by existing lint. Tier B (equational + bounded-quantified cells) gets a kernel: the decidable fragment of the internal language of `Set^𝒦` — bounded ∀/∃ over finite I(k), equality, comparisons, ∧/¬, reference-typed atomics — implemented over the acset substrate, emitted by unique functors to TLA+/Rust/pytest/TS. Tier C keeps the `**tag:**` opaque escape hatch and a per-constraint opaque `binding` column bridging external checkers through contract-TOML `flags`. Guard citation semantics ships as kernel slice 1. Openspec candidate: `add-min-expr-kernel`.
