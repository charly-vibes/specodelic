# specodelic

> Markdown specification format and toolchain for AI agents — plain markdown
> with a closed four-table schema (Constraints, Model, Properties), checked by
> a self-hosting linter. The CLI binary is `spk` (crate: `specodelic`).

## What It Does

specodelic specs are markdown files: YAML frontmatter (`id`, `kind`, one EARS
`statement`) plus three fixed tables — Constraints, Model, Properties. The
linter never parses prose; all semantics live in the structured rows, so prose
stays free. Every structured `[[wiki-link]]` must resolve; every constraint
needs a deriving property; every model transition needs a guard.

- **Frontmatter** — `id`, `kind`, and a single EARS statement
- **Constraints** — invariant/effect rows that other specs may derive from
- **Model** — states with guarded transitions
- **Properties** — deriving rows pairing a generator with a predicate

## Key Commands

```
specodelic lint <path>     # lint spec files (alias: spk)
```

## Install

```bash
# macOS & Linux (curl — resolves the latest release automatically)
V=$(basename "$(curl -fsSLI -o /dev/null -w '%{url_effective}' \
  https://github.com/charly-vibes/specodelic/releases/latest)" | sed 's/^v//')
TGT="$(uname -s | tr '[:upper:]' '[:lower:]')_$(uname -m | sed 's/^x86_64$/amd64/; s/^aarch64$/arm64/')"
curl -fsSL "https://github.com/charly-vibes/specodelic/releases/download/v${V}/specodelic_${V}_${TGT}.tar.gz" | tar xz
chmod +x specodelic spk && sudo mv specodelic spk /usr/local/bin/
```

Or via Cargo: `cargo install specodelic`.
