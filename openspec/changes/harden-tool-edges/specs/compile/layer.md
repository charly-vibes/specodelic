# compile — dual-format layer (sidecar)

## Purpose

`specodelic.md` names `compile` as the transition from `linted` to
`compiled`, gated on `coverage` and `law_requires_cases`, but never
specifies what compiling actually *produces* (`STATUS.md` §4, P0). This
file is that specification: `Compile` is the functor `Set^𝒦 → TOML`
(constraints), `Set^𝒦 → TLA+` (the model), and
`Set^𝒦 → proptest!` (properties) that `STATUS.md` §1 describes — one
functor with three target categories, not three unrelated tools that
happen to run at the same pipeline stage.

## Model

### States
- `not_started`
- `extracting`
- `emitting`
- `compiled`
- `extract_failed` (emits: `[[compile.layer.extraction_failure]]`)
- `emit_failed` (emits: `[[compile.layer.emission_failure]]`)

### Transitions

| id           | from        | to          | guard                                                                                             |
|--------------|-------------|-------------|--------------------------------------------------------------------------------------------------------|
| begin        | not_started | extracting  | [[compile.layer.precondition_satisfied]] ∧ [[compile.layer.artifact_stem_unique]]                                                                     |
| extract_ok   | extracting  | emitting    | [[compile.layer.constraint_table_to_toml]] ∧ [[compile.layer.model_to_tla]] ∧ [[compile.layer.properties_to_proptest]]     |
| extract_fail | extracting  | extract_failed | `¬([[compile.layer.constraint_table_to_toml]] ∧ [[compile.layer.model_to_tla]] ∧ [[compile.layer.properties_to_proptest]])` |
| accept       | emitting    | compiled    | [[compile.layer.compile_preserves_ids]] ∧ [[compile.layer.no_semantic_drift]]                                       |
| reject       | emitting    | emit_failed | `¬([[compile.layer.compile_preserves_ids]] ∧ [[compile.layer.no_semantic_drift]])`                                    |
