---
id: compile.layer
kind: intent
statement: "WHEN a linted, coverage-satisfied corpus file is compiled, THE compile capability SHALL translate the three layer tables into their artifact forms field-for-field — Constraints to TOML, Model to TLA+, Properties to proptest blocks (with typed generator opt-ins and per-language emitters for the tags the closed set specifies) — preserving every id, failing labeled on any extraction or emission stage failure, and never emitting a silent partial result."
---

## Model

### States
- `not_started`
- `extracting`
- `emitting`
- `compiled`
- `extract_failed` (emits: `[[compile.layer.extraction_failure]]`)
- `emit_failed` (emits: `[[compile.layer.emission_failure]]`)

### Transitions

| id           | from        | to          | guard                                                                                             |
|--------------|-------------|-------------|--------------------------------------------------------------------------------------------------------|
| begin        | not_started | extracting  | [[compile.layer.precondition_satisfied]]                                                                     |
| extract_ok   | extracting  | emitting    | [[compile.layer.constraint_table_to_toml]] ∧ [[compile.layer.model_to_tla]] ∧ [[compile.layer.properties_to_proptest]]     |
| extract_fail | extracting  | extract_failed | `¬([[compile.layer.constraint_table_to_toml]] ∧ [[compile.layer.model_to_tla]] ∧ [[compile.layer.properties_to_proptest]])` |
| accept       | emitting    | compiled    | [[compile.layer.compile_preserves_ids]] ∧ [[compile.layer.no_semantic_drift]]                                       |
| reject       | emitting    | emit_failed | `¬([[compile.layer.compile_preserves_ids]] ∧ [[compile.layer.no_semantic_drift]])`                                    |
